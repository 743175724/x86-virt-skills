**Scope.** Every claim line in both chapters, not a sample. 367 claims checked.
Line numbers are those of the **pre-edit** files (commit `70a5da7`).

in **both** `-layout` and `-raw` modes — the appendix and table pages column-desync in layout
mode, and Table C-1 in particular has to be reconstructed by matching the number column against
the description column in raw reading order. No verdict below rests on memory or a secondary source.

## Verdict key

- **CONFIRMED** — the PDF says this, at (or inside) the cited section.
- **WRONG** — the PDF contradicts it. The correction is given with the quoted text.
- **UNSUPPORTED** — the value may be right, but the cited section does not contain it (mis-anchor),
  or the claim asserts something no section states (including "could not be verified" hedges that
  are now false).
- **UNVERIFIABLE** — neither PDF settles it.
