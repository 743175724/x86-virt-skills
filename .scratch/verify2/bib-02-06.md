## New entries

```
[170] Intel. Intel 64 and IA-32 Architectures Software Developer's Manual, Volume 3 (3A, 3B, 3C & 3D): System Programming Guide — combined. Order 325384-092US. Rev 092, June 2026. https://cdrdv2.intel.com/v1/dl/getContent/671447 — T1
```

**Why this entry exists.** Bibliography `[3]` (Vol.3A, order 253668) and `[4]` (Vol.3B, order 253669)
both point at `getContent/671447` and describe it as "served inside the Volume 3 combined PDF."
That is right, but the cover page of the file actually served is
`Intel® 64 and IA-32 Architectures Software Developer's Manual, Volume 3 (3A, 3B, 3C, & 3D): System
Programming Guide`, **Order Number 325384-092US**, June 2026 — a fourth order number that appears
nowhere in the bibliography. The HLAT claims in `06-address-translation.md` §6.10 cite Vol.3A
§5.5.1 / §5.5.4 / §5.5.5, and those sections were read out of this file. `[170]` names the artefact
that was text-extracted, so a reader reproducing the check downloads the same bytes.

`[3]` and `[4]` remain correct as *logical* volume references and are unchanged; `[170]` is the
*physical* download. A future bibliography edit should add the cross-reference
"`[3]`, `[4]`, `[170]` are one download" in the same style as the existing "(same file as `[4]`)" note.
